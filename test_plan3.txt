When banned, they are NOT logged out automatically. Why?
In `HomePage.tsx`:
```
    const handleBanLogout = (data: any) => {
      const myId = localStorage.getItem('accountNumber');
      if (myId === data.accountId) {
        localStorage.clear();
        window.location.reload();
      }
    };
```
Why wouldn't `myId === data.accountId` be true?
Because `localStorage.getItem('accountNumber')` could be different, or maybe the data being sent from `backend/server.js` doesn't have the same type (e.g. number vs string).
`io.emit('banned_logout', { accountId: data.accountId });`
`data.accountId` comes from the `ownerban.tsx`: `accountId: targetUser.accountId`.
But what if the user was banned by device ID, or they just log in again because `localStorage.clear()` isn't enough to log them out from Firebase!
If `localStorage.clear()` is called and `window.location.reload()` is triggered, `app/page.tsx` will remount.
In `app/page.tsx`, `onAuthStateChanged` is called. If the user didn't `signOut(auth)`, Firebase STILL sees them as logged in, and `setIsLoggedIn(true)` will be called!
YES! `localStorage.clear()` DOES NOT CLEAR FIREBASE AUTH SESSION!
So when the page reloads, Firebase logs them right back in automatically without checking `/api/check-ban`!
Because `/api/check-ban` is ONLY called inside `LoginPage.tsx` when they manually log in!
